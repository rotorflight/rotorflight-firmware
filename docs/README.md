# Firmware docs

All documentation lives in the
[rotorflight-documentation](https://github.com/rotorflight/rotorflight-documentation) repository,
published at <https://doc.rotorflight.org>: the user guides, the CLI reference, and the developer
material under Contributing (building the firmware, coding style and the
[Technical Reference](https://doc.rotorflight.org/contributing/tech/)).

This directory intentionally holds nothing else. Do not add documents here; add them to
rotorflight-documentation and, if source code depends on one, link to it by URL. See
[AGENTS.md](../AGENTS.md) for the working rules.
